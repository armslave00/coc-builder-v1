# 分别记录出版身份、数据覆盖与人物持有物

现代日本有 KADOKAWA 官方扩展，维多利亚背景有 Gaslight 官方资料；当前目录未包含完整数据不意味着这些扩展不存在。产品介绍能核实书名、版次与范围，不能还原原书未公开的职业或装备表。因此分别维护资料来源和可用于建卡的条目，并为来源记录职业、技能与装备的覆盖状态；尚未导入的书目不生成可玩 profile，也不声称规则已支持。

优先录入公开官方或授权表中可核实的机械数值、价格与选择条件，中文描述独立撰写。人物卡、公开规则页和完整书目分别注明，避免把相同设定的不同证据混为整书覆盖。旧版资料登记版次，未经逐项转换不直接作为第 7 版数值。

人物已经记录的武器数值是人物持有物的一部分。目录更新用于新添加装备；已有库存采用保存值，缺少新增字段时才回退到定义。时代切换保留库存与技能分配，并提示检查适用性。这样能在扩充来源和纠正距离单位的同时，保留已有档案的玩家设定和跑团记录。
