# 阿卡姆档案馆 · COC 7 调查员角色卡

纯前端的《克苏鲁的呼唤》第 7 版角色卡工具。React + TypeScript + Vite，无账号、数据库或运行时服务端，数据保存于浏览器 localStorage。

## 使用

需要 Node.js 22 或以上。

```sh
npm install
npm run dev
```

```sh
npx playwright install chromium
npm test
npm run build
npm run preview
```

PDF 分页回归检查使用 Chromium 实际生成 A4 PDF，验证第一页包含完整技能和页脚、普通角色共两页，以及长背景、大量装备和原创技能增页时不丢失内容。首次运行需安装测试浏览器：

```sh
npx playwright install chromium
npm run test:pdf
npm run check
```

`npm test` 包含单元测试和 PDF 回归检查；`npm run test:pdf` 可单独检查分页；`npm run check` 运行全部测试和生产构建。Linux 环境需要中文字体，例如 `fonts-noto-cjk`。生成的检查文件位于 `test-results/pdf/`，不提交到 Git。

`dist/` 是可直接上传到静态 CDN 的完整产物，已配置相对资源路径，兼容 GitHub Pages 项目子目录。开发默认地址为 `http://127.0.0.1:5173/`。

## 部署到 GitHub Pages

1. 项目仓库为 [armslave00/coc-builder-v1](https://github.com/armslave00/coc-builder-v1)，项目使用 `master` 分支。
2. 在 Settings → Pages → Build and deployment 中选择 **GitHub Actions**。
3. 推送到 `master` 或手动运行项目内的 **Deploy to GitHub Pages** 工作流。

PR 会运行 **Regression gate**；部署也必须先通过相同门禁（单元测试、实际 PDF 分页检查和生产构建）。失败会阻止部署，检查生成的 PDF 会保留为 Actions 附件 7 天。若需阻止失败的 PR 合并，可在仓库分支保护中将 **Tests, PDF pagination and build** 设为必需状态检查。若使用其他分支，请修改 `.github/workflows/deploy.yml` 的分支名。Cloudflare Pages、Netlify 等平台的构建命令为 `npm run build`、输出目录为 `dist`。没有服务端环境变量。

## 功能

- 多角色创建、复制、删除、自动保存，四个原创示例调查员。
- 最终属性、标准掷骰、一次性年龄调整及教育成长检查。
- 自动 HP、MP、初始 SAN、神话理智上限、MOV、体格与伤害加值。
- 职业及个人兴趣点预算、固定/可选职业技能、成长记录、半值和五分之一计算。
- 属性与体格的分段扮演提示、120 项技能的悬停／聚焦／点击简介与场景。
- 191 个职业、120 项技能、481 件装备与武器；职业卡片弹窗、时代筛选与资料搜索。
- 35 条书目与来源，分别展示职业、技能、装备的收录状态；换职业保留加点并提示职业要求。
- 武器与物品分区、时代装备筛选、装弹量及故障值编辑、固有徒手、护甲手动记录、生活水平及独立财产记录、法术和背景故事。
- 原创技能、职业、装备、法术和设定；原创数据以 JSON 保存、导入导出。
- 单角色 JSON、全部档案备份、独立 HTML 人物卡及 A4 浏览器 PDF 打印。
- 桌面编辑工作区与移动端抽屉导航；触控、键盘和减少动效支持。
- 严格的 JSON schema / 字段 / 数值导入检查；HTML 输出转义、CSP 无脚本。

## 数据与规则边界

预置共享内容维护在 `src/data/core.json`，各时代差异维护在独立 JSON，通过 `src/data/rules.ts` 组合；来源和版本见 [docs/rules-sources.md](docs/rules-sources.md)。公开普通装备表的 215 个有价格实物行已对应目录；武器表的 44 行均有对应条目，少数独立专长和字段仍待规则书核实。目录并非完整重新发行核心及所有扩展规则书。

用户提供的人物卡 Excel 另补入 165 个职业、46 项技能和 206 项装备，统一标为“用户提供参考”；原表混有旧版、自定义与试运行内容，未覆盖既有公开核实数值。属性和体格文案参考其表内锚点重写，计算规则不变。逐行去重、暂缓理由和数值冲突见 [Excel 审计](docs/excel-reference-audit.md)。打印人物卡仅列角色实际使用的具体专长，全部专长仍可在技能页和资料库选择。

提供经典、煤气灯、黑暗时代、西部拓荒、日本现代、维多利亚共 6 个选项。煤气灯、黑暗时代（第三版）、西部拓荒编码公开官方人物卡的技能差异。现代日本关联 KADOKAWA 官方日文第 7 版《クトゥルフ2020》《クトゥルフ2026》；现有日本技能基础值来自核心现代人物卡，日版专属职业和装备尚未导入。通用职业只作时代适配，不冒称扩展专属目录完整收录。

经典规则为第 7 版。煤气灯使用 2024 版及官方人物卡的时代技能差异；维多利亚风格共用煤气灯机制；日本现代是第 7 版现代规则的设定适配，明确标注其身份。法术提供名称及用途索引，不伪造未能从公开官方资料核对的代价；施法细节以对应规则书为准。

角色属性框表示**年龄调整后的最终值**，示例已调整。随机生成后才使用一次年龄调整按钮；不要重复应用。年龄减值默认优先从当前最高身体属性扣除，规则允许玩家手动重新分配。切换时代保留已填写数据，不自动删除旧技能点；请检查当前职业/时代的可用技能和点数提示。

localStorage 按域名和浏览器隔离，不提供云同步；清除网站数据会删除档案。请用「备份整个档案馆」保存 JSON 后再换设备/域名。图片以 data URI 保存在本地；首次示例肖像为随站点打包的原创生成资产。网页字体的可选 Google Fonts 加载失败时自动回退至本地宋体与 Georgia，功能和数据均可脱网使用（首次需加载站点资源；不包含 Service Worker 离线缓存）。

PDF 通过浏览器打印引擎生成，选择「另存为 PDF」、A4 并关闭页眉页脚。长背景或很多装备将自动增页，不截断数据。
